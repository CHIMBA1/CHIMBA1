Início Sobre o Projeto

Descrição

Este site foi desenvolvido utilizando HTML e CSS básicos. O objetivo é demonstrar a criação de páginas Web simples, organizadas e ligadas entre si por meio de links.

Tecnologias utilizadas

  • HTML5
  • CSS básico
  • Links entre páginas

Conclusão

A atividade ajudou a compreender como uma página é estruturada e como o navegador interpreta o código para apresentar o conteúdo ao usuário.
