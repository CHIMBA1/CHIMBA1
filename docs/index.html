Início Sobre o Projeto

O que é HTML?

HTML significa HyperText Markup Language. É uma linguagem de marcação utilizada para organizar e estruturar conteúdos de páginas da Web, como textos, títulos, imagens, links, listas e formulários.

Navegadores Web

Os navegadores são programas utilizados para acessar páginas da internet. Entre os mais conhecidos estão Google Chrome, Mozilla Firefox, Microsoft Edge, Safari e Opera.
